## 一起看

点击右上角的“一起看”，输入昵称后创建房间，或粘贴朋友的邀请加入。房主打开短剧后，其他成员会跟随播放。

- 房间内可查看正在共看的短剧、分集和播放状态。
- 朋友可以“暂停同步”临时自己看，再用“回到同步”继续跟随房主。
- 聊天窗口支持放大、拖动和固定；表情先插入输入框，按 Enter 或点击发送。
- 向上阅读历史消息时不会被新消息打断，点击新消息提示可回到最新内容。
- 网络断开后自动重连，聊天草稿和房间状态会保留。
