Windows 桌面短剧、小说阅读与朗读程序。本仓库用于发布安装包、更新说明和接收问题反馈；源码不在此仓库提供。

## 使用与反馈

播放报错或画面长时间不动时，可在播放页“设置 → 修复播放”重试。问题反馈请提交到 [Issues](https://github.com/doppe7gangar/duanju/issues)，并注明软件版本、Windows 版本和复现步骤。
