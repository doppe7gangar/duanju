# 果剧桌面

自制的 Windows 桌面短剧、小说和朗读程序。界面与桌面外壳由本项目实现；短剧检索播放、小说正文和公开评论分别接入开源组件。软件自身不展示广告，内容来源、可用剧目及播放限制由上游平台决定。

本程序不是红果短剧官方客户端，也没有得到平台授权或背书。上游接口变化时，搜索或播放可能失效。不要在未经核实的第三方程序中输入红果账号密码；本版本无需账号登录。

## 开发运行

```powershell
npm.cmd install
npm.cmd start
```

## 生成 Windows 便携版

```powershell
npm.cmd run build
```

产物在 `dist/`，无需安装安卓模拟器。Windows 视频解码能力和上游片源会影响实际播放结果。

## 操作

- “首页”直接读取红果官网公开的首页横幅（自动轮播）、推荐片单，以及真人、漫剧、AI 分类目录；向下滑动会继续加载，片单可左右浏览。热门推荐是榜单，剧目数量比分类页少；点右上角放大镜输入剧名后按 Enter。
- “真人短剧 / 漫剧 / AI 短剧”读取红果官网分类目录（每类最多 800 部，下滑自动加载），可用“题材”下拉筛选；官网不可用时自动改用 App 目录。“演员”可从演员榜进入参演作品。
- “刷剧”像手机短视频一样一部接一部自动播放推荐短剧（从第 1 集开始，已经看过的剧会跳过）：滚轮、↑↓ 方向键或上下拖动画面换一部，空格暂停，M 静音；一集播完自动接下一集。点“看全集”（或按 Enter）用完整播放器从当前位置接着看，返回后继续刷下一部。看满 15 秒的剧会进入“继续观看”。
- 点击剧集卡片打开详情：简介、类型、演员、选集；卡片上的橙色圆钮直接播放，＋ 加入“我的片单”。
- “我的”汇总继续观看、我的片单和最近阅读，均只保存在本机。
- 播放页的画质、速度和弹幕在“设置”里；“弹”按钮开关弹幕（默认开启），评论里的 [表情] 显示为 emoji。竖屏短剧两侧会用画面颜色柔光填充。
- 空格暂停或继续；左右方向键快退 / 快进 10 秒；上下方向键切换分集；F 全屏，M 静音，D 弹幕，Esc 返回。
- 本机保存每部剧最近播放集数与进度。
- “小说阅读”直接读取番茄小说官网的编辑推荐、热门与精选书单，并补充按题材搜索的探索书单；下滑自动加载，也可搜索书名。这些是番茄官网公开书目，不能视为红果 App 的完整小说库。
- “小说朗读”使用 Windows 系统语音朗读网站可见文字章节，点书后开始朗读，可调整速度并连续听章。目前未接入红果或番茄畅听官方录制的有声书音轨。
