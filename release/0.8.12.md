# 果剧桌面 0.8.12

优化朋友加载较慢时的一起看同步，并接入直连更新源。

- 新增准备/缓冲状态反馈，房主可等待慢速朋友，最多 25 秒，可关闭等待或点播放继续。
- 缓冲期间不再反复跳转追赶；恢复后对齐，限制连续跳转，缓冲不足时不加速。新加入房间直接从房主进度开始加载。
- 保留手动暂停，自动同步不会反向误发控制；最近视频块复用，减少重复下载。
- 检查和下载安装更新优先走 together.qqkid.link，签名与 SHA256 校验；保留 GitHub 备用入口。
- 服务端已升级协议 v3，双方更新到 0.8.12 后可使用完整的就绪反馈。旧版仍兼容加入。

验证：49 项基础/播放/同步回归、6 项 WebSocket 协议测试、双客户端实际脚本与模拟媒体集成、6 项部署回归通过；线上部署通过本机/公网双端 WebSocket、更新清单、安装包分段下载与服务健康检查。

限制：未完成实际显卡、片源与跨地区网络实播，不能保证消除所有卡顿；上游播放组件首次准备异常仍需单独处理。
